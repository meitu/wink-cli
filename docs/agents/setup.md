# 在当前 Agent 中连接 Wink（远程 MCP）

请通过 Wink 远程 MCP 为用户建立连接。本文适用于豆包、千问及其他 Agent 的接入测试，不要求终端、Node.js、npm 或本地 CLI。用户说“按本文连接 Wink”，授权的是配置连接、发起账号授权及只读验证，不包含素材上传、付费处理或购买套餐。

**先检查工具能力，不要因为没有 shell 就停止。** 远程 MCP 不需要 shell，但当前宿主必须已经接入 Wink，或支持添加远程 MCP / 应用插件。阅读本 Markdown 不会自动给一个普通网页聊天会话增加外部工具权限。

## 1. 先检查当前会话已有的工具

检查宿主实际提供的工具清单，查找来自 Wink 的远程工具。命名空间可能不同，不要仅按某个固定前缀判断。

当前服务包含以下工具，可据此识别：

- `task_ai_type_config`：查询云处理能力与素材限制。
- `material_ai_beauty_list`：查询真实 AI 美容风格。
- `task_submit`：提交云处理任务，可能消耗额度；连接验证时不要调用。
- `task_query`：查询已经提交的任务。

如果这些工具已经存在，直接进入第 3 步，复用现有连接，不重复安装、不换账号、不要求用户提供密钥。

不要编造 `connect_mcp`、`install_skill` 或其他宿主没有提供的工具。如果没有 Wink 工具，继续检查宿主是否提供添加 MCP、安装插件或管理员配置入口。

## 2. 没有工具时，按宿主真实支持的方式配置

Wink 生产环境远程服务：

| 配置项 | 值 |
| --- | --- |
| 名称 | Wink |
| 服务地址 | `https://cliapi-winkcut.meitu.com/mcp` |
| 传输协议 | Streamable HTTP |
| 认证 | OAuth，由宿主管理授权、Token 保存与刷新 |
| Scope | `wink:mcp`，以服务端元数据及宿主要求为准 |

下列是通用连接配置示例，不是可以通过聊天直接执行的指令。字段名称需遵循当前宿主的配置规范；例如有的宿主使用 `streamableHttp`，有的使用 `streamable-http`。

```json
{
  "mcpServers": {
    "wink": {
      "type": "streamableHttp",
      "url": "https://cliapi-winkcut.meitu.com/mcp"
    }
  }
}
```

### 宿主提供 MCP 配置或插件安装能力

1. 使用宿主实际提供的添加服务或插件入口，填写上述生产服务地址及 Streamable HTTP 协议。
2. 使用宿主支持的 OAuth 流程。OAuth 端点、资源与 issuer 优先通过服务端标准元数据发现，不拼接一次性授权链接，不自行兑换 Token。
3. 如果宿主要求 OAuth Client ID，且无法自动注册，不猜测、不复用其他平台的客户端身份。由 Wink 服务端为该宿主登记独立 Client ID 和精确回调地址后再连接；当前文档没有提供豆包、千问专用 Client ID。
4. 不能直接照搬 Codex / ChatGPT 的 `wink-codex`、OpenAI 专属配置、localhost 回调或其他平台的回调地址。OAuth 接入是否兼容，以本平台的实际连接结果为准。
5. 完成宿主要求的加载或刷新后，重新检查第 1 步的真实工具清单。

### 宿主没有添加 MCP 或插件的能力

不要让用户安装 CLI 来解决一个没有终端的网页会话，也不要反复要求用户发送同一条连接提示词。明确报告：

> 我已读取 Wink MCP 接入说明，但当前会话没有 Wink 工具，也没有添加远程 MCP 的入口，因此暂时不能在这段对话里执行 Wink 处理。需要先由平台或管理员接入 Wink MCP / 应用插件。你也可以先打开 Wink 网页处理素材。

提供 [打开 Wink 视频美容](https://wink.cn/video-retouch/upload) 作为可用的网页入口，不把“能打开网页”表述成“当前 Agent 已连接”。

平台接入参考：

- 豆包应用插件通过 MCP Server 和 Skill 接入；平台当前说明采用邀请制，需要先完成开发者接入，而非向普通聊天粘贴 MD 就安装成功：[豆包官方说明](https://open.doubao.com/apps-plugin/docs/overview/introduction)。
- 千问模型用于阿里云百炼 Agent 时，可由开发者配置自定义远程 MCP；这不等于每个千问消费端网页会话都有同样入口：[百炼官方说明](https://help.aliyun.com/zh/model-studio/managed-agents-custom-mcp-skills)。

## 3. 完成 Wink OAuth 授权

已有有效授权时直接复用。需要授权时，使用宿主真实的“连接 / 登录 / 授权”入口，由用户在 Wink 授权页登录、确认账号并同意授权。

- Token、授权码交换及刷新由宿主管理。不要向用户索要 API Key、Access Token、密码或授权码，不读取 Cookie，不让用户把密钥粘贴到对话里。
- 只展示宿主实际生成的授权链接，不手写 `state`、`redirect_uri` 或授权码。打开网页不等于授权完成。
- 用户完成授权后，重新检查工具是否可用。若授权回调失败，报告实际错误，核对本平台 Client ID 与回调白名单，不反复登录、不改走 CLI 凭据。
- 服务地址保持生产环境，不自动切换预发或测试环境。不把 `client=doubao` 等入口查询参数加入 OAuth state、Token 或处理参数。

## 4. 通过真实工具做只读在线验证

先阅读当前宿主暴露的工具参数结构，再调用 Wink 的 `task_ai_type_config`。参数只使用工具实际支持的字段；若支持 `client_language`，中文会话可传 `zh-Hans`。

没有权限调用该工具时，可用同一连接下实际存在的只读工具（例如 `material_ai_beauty_list`）验证；不要猜测不存在的工具或绕过鉴权。

成功标准：工具真实执行成功、无 `isError=true`，业务响应成功且返回有效能力或风格数据。只出现工具名或授权成功提示，不足以证明在线查询通过。

如实报告请求失败、鉴权失败或业务错误。不为验证连接提交 `task_submit`、上传素材或消耗美豆。不把在线查询成功表述成所有功能、SVIP 权益和余额都已验证。

## 5. 读取 Skill 与检查素材处理能力

本文是连接 Skill 指引。支持宿主加载 Markdown 说明时，将其作为当前会话的连接流程；只有宿主提供并实际完成持久 Skill 安装时，才称为“已安装 Skill”。无需写入本地技能目录或运行 shell。

实际处理前，使用宿主已接入的 Wink 业务 Skill、当前工具描述和 `task_ai_type_config` 返回的能力配置。若没有处理 Skill，不能照搬其他宿主包里依赖本地 Node.js 的上传或参数脚本。

**MCP 工具可调用，不代表附件上传也已接通。**

- 先确认宿主是否能为用户本轮附件提供真实、可供 Wink 获取的媒体地址，或是否已集成可用的 Wink 文件上传能力。
- 用户电脑上的文件路径、聊天附件 ID、`blob:` 地址、缩略图及 `file://` 地址，不是远程 MCP 可以直接读取的素材 URL。
- 若宿主只能提供需要其私有登录态才能下载的附件，不擅自公开附件、不转发宿主 Token，不让 Wink 服务访问任意内网地址。
- 当前 Wink 桌面插件中的本地 JS 上传方式需要本地运行时，不能要求无终端的豆包、千问网页会话直接执行。
- 缺少适用的上传能力时，报告“远程工具已连接，但本会话的附件上传尚未接入”。可引导使用 Wink 网页；不要承诺网页上传结果会自动回传到 Agent，除非该关联能力已实际实现。

收到真实处理请求后，先确认功能、档位、附加效果和素材数量，再按已接入 Skill 的流程执行。素材可用、业务参数可核验且用户已授权后，才可提交可能收费的任务。连接期间不自动执行任何处理。

## 6. 输出连接结果

根据实际完成阶段回复，不混用以下状态：

1. 已读取本文，但当前宿主无 MCP 接入能力。
2. 已填写服务配置，尚未完成账号授权或工具加载。
3. 已授权且只读工具验证成功，素材上传尚未接通。
4. 已授权、只读查询通过，且当前宿主具有已验证的素材处理路径。

只在第 4 种情况下可回复：

> Wink 远程 MCP 已连接，账号授权和只读查询已通过，本会话也具备素材接入能力。你可以发送图片或视频并说明想要的效果；实际云处理可能消耗账户额度。

如果未完成，简短说明具体缺少的能力和需要平台或管理员完成的动作。不因无法调用工具而假装已连接，不把服务端的会员提示直接推断成必须购买会员。

入口地址可以使用 `https://wink.cn/agents/setup.md?client=doubao` 或 `?client=qianwen`；查询参数仅用于区分入口来源，不授予权限、不更换服务地址，也不代表已经完成平台插件接入。
